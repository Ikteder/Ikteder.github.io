# Decision 0001: Use the root GitHub Pages URL as the canonical portfolio

Date: 2026-08-24

## Decision

Publish the full portfolio at `https://ikteder.github.io/` and redirect the older `https://ikteder.github.io/Portfolio/` route to the canonical root.

## Rationale

- The root URL is shorter and is the address visitors are most likely to try first.
- The former root was an outdated 2021 placeholder, creating a misleading first impression.
- Redirecting the older project URL preserves existing bookmarks and search results.

## Content rules

- Feature a curated set of flagship projects instead of treating every repository equally.
- Separate peer-reviewed papers, preprints, and current research.
- Tie quantitative claims to publisher or repository evidence.
- Do not represent SPARQ as published until a public publication record exists.
